# German A1 Grammar Cheat Sheet

---

# 1. Artikel (Articles)

Articles always come **before a noun**.

## Types of Articles

| Gender    | Definite (the) | Indefinite (a/an) | Negative (no/not a) |
| --------- | -------------- | ----------------- | ------------------- |
| Masculine | der            | ein               | kein                |
| Feminine  | die            | eine              | keine               |
| Neuter    | das            | ein               | kein                |
| Plural    | die            | —                 | keine               |

### Examples

- der Mann → a man
- ein Mann → a man
- kein Mann → no man

- die Frau
- eine Frau
- keine Frau

- das Auto
- ein Auto
- kein Auto

- die Autos
- keine Autos

### Basic Rules

- **der** → Masculine nouns
- **die** → Feminine nouns
- **das** → Neuter nouns
- Plural nouns always use **die**
- There is **no plural form of "ein/eine"**
- Use **kein/keine** to make nouns negative.

Example

- Ich habe ein Auto.
- Ich habe kein Auto.

# 2. Personalpronomen (Personal Pronouns)

| Person | Pronoun | Number          |
| ------ | ------- | --------------- |
| 1st    | ich     | Singular        |
| 2nd    | du      | Singular        |
| 3rd    | er      | Singular        |
| 3rd    | sie     | Singular        |
| 3rd    | es      | Singular        |
| 1st    | wir     | Plural          |
| 2nd    | ihr     | Plural          |
| 3rd    | sie     | Plural          |
| Formal | Sie     | Singular/Plural |

### Basic Rules

- **ich** = I
- **du** = you (informal)
- **Sie** = you (formal)
- **er** = he
- **sie** = she
- **es** = it
- **wir** = we
- **ihr** = you (plural)
- **sie** = they

Remember

- **sie** = she
- **Sie** = You (formal)
- Capital **S** changes the meaning.

# 3. Verb "sein", "haben" and "heißen"

These are the three most important verbs in German.

| Pronoun | sein (to be) | haben (to have) | heißen (to be called) |
| ------- | ------------ | --------------- | --------------------- |
| ich     | bin          | habe            | heiße                 |
| du      | bist         | hast            | heißt                 |
| er      | ist          | hat             | heißt                 |
| sie     | ist          | hat             | heißt                 |
| es      | ist          | hat             | heißt                 |
| wir     | sind         | haben           | heißen                |
| ihr     | seid         | habt            | heißt                 |
| sie     | sind         | haben           | heißen                |
| Sie     | sind         | haben           | heißen                |

### Basic Rules

- **sein** describes identity or state.

Example

- Ich bin Student.
- Sie ist Lehrerin.

- **haben** expresses possession.

Example

- Ich habe ein Buch.
- Wir haben Zeit.

- **heißen** tells someone's name.

Example

- Ich heiße Yanis.
- Wie heißt du?

# 4. Regular Verb Conjugation (Präsens)

Most German verbs follow the same pattern.

## Endings

| Pronoun   | Ending |
| --------- | ------ |
| ich       | -e     |
| du        | -st    |
| er/sie/es | -t     |
| wir       | -en    |
| ihr       | -t     |
| sie       | -en    |
| Sie       | -en    |

### Example: machen (to do)

| Pronoun   | machen |
| --------- | ------ |
| ich       | mache  |
| du        | machst |
| er/sie/es | macht  |
| wir       | machen |
| ihr       | macht  |
| sie       | machen |
| Sie       | machen |

### Common Daily Verbs

| English | German Infinitive | ich      | du        | er/sie/es |
| ------- | ----------------- | -------- | --------- | --------- |
| do/make | machen            | mache    | machst    | macht     |
| learn   | lernen            | lerne    | lernst    | lernt     |
| live    | wohnen            | wohne    | wohnst    | wohnt     |
| work    | arbeiten          | arbeite  | arbeitest | arbeitet  |
| come    | kommen            | komme    | kommst    | kommt     |
| go      | gehen             | gehe     | gehst     | geht      |
| play    | spielen           | spiele   | spielst   | spielt    |
| buy     | kaufen            | kaufe    | kaufst    | kauft     |
| drink   | trinken           | trinke   | trinkst   | trinkt    |
| eat     | essen\*           | esse     | isst      | isst      |
| read    | lesen\*           | lese     | liest     | liest     |
| speak   | sprechen\*        | spreche  | sprichst  | spricht   |
| write   | schreiben         | schreibe | schreibst | schreibt  |
| cook    | kochen            | koche    | kochst    | kocht     |
| sleep   | schlafen\*        | schlafe  | schläfst  | schläft   |

> \*These verbs are irregular (stem-changing).

### Basic Rules

- The verb is usually the **second element** in a German main sentence.

Example

- Ich lerne Deutsch.
- Wir wohnen in Berlin.

- Every sentence needs a conjugated verb.
- Change the verb according to the subject.

Formula

> Subject + Verb + Object

Example

- Ich kaufe Brot.
- Du lernst Deutsch.
- Er arbeitet heute.

# 5. Basic German Sentence Patterns

## Statement

> Subject + Verb + Object

- Ich lerne Deutsch.
- Wir trinken Kaffee.

---

## Yes/No Question

> Verb + Subject + Object?

- Kommst du?
- Hast du Zeit?
- Ist das dein Auto?

---

## W-Question

> Question Word + Verb + Subject + ...?

| German    | English    |
| --------- | ---------- |
| Wer       | Who        |
| Was       | What       |
| Wo        | Where      |
| Wohin     | Where to   |
| Woher     | Where from |
| Wann      | When       |
| Warum     | Why        |
| Wie       | How        |
| Wie viel  | How much   |
| Wie viele | How many   |

Examples

- Wie heißt du?
- Wo wohnst du?
- Was machst du?

---

# 6. Word Order Rules

### Rule 1

The conjugated verb is always in Position 2.

Example

- Ich lerne Deutsch.
- Heute lerne ich Deutsch.

### Rule 2

Time usually comes before place.

Example

- Ich arbeite heute in Berlin.

### Rule 3

In Yes/No questions, the verb comes first.

Example

- Hast du Zeit?

---

# 7. Negation

## nicht

Used to negate verbs, adjectives, and whole sentences.

Examples

- Ich komme nicht.
- Das ist nicht gut.

## kein

Used to negate nouns.

Examples

- Ich habe kein Auto.
- Wir haben keine Kinder.

---

# 8. Quick Formula

Article + Noun

> ein Auto

Pronoun + Verb

> Ich lerne.

Subject + Verb + Object

> Ich lerne Deutsch.

Question

> Wo wohnst du?

Negative

> Ich habe kein Auto.

# 9. Modalverben (Modal Verbs)

Modal verbs are helping verbs. They change the meaning of the main verb.

## Basic Rule

**Sentence Structure**

> Subject + Modal Verb + Object + Main Verb (Infinitive)

Examples

- Ich **kann** Deutsch **sprechen**.
- Du **musst** heute **arbeiten**.
- Wir **wollen** Pizza **essen**.

The **modal verb is conjugated**, while the **main verb stays in the infinitive and goes to the end of the sentence.**

---

## The Six Modal Verbs

| German | English              | Usage                |
| ------ | -------------------- | -------------------- |
| können | can / be able to     | ability, possibility |
| müssen | must / have to       | necessity            |
| wollen | want to              | desire               |
| sollen | should / supposed to | advice, obligation   |
| dürfen | may / be allowed to  | permission           |
| mögen  | like                 | preference           |

---

## Conjugation

| Pronoun   | können | müssen | wollen | sollen | dürfen | mögen |
| --------- | ------ | ------ | ------ | ------ | ------ | ----- |
| ich       | kann   | muss   | will   | soll   | darf   | mag   |
| du        | kannst | musst  | willst | sollst | darfst | magst |
| er/sie/es | kann   | muss   | will   | soll   | darf   | mag   |
| wir       | können | müssen | wollen | sollen | dürfen | mögen |
| ihr       | könnt  | müsst  | wollt  | sollt  | dürft  | mögt  |
| sie       | können | müssen | wollen | sollen | dürfen | mögen |
| Sie       | können | müssen | wollen | sollen | dürfen | mögen |

---

## Examples

### können (can)

- Ich kann Deutsch sprechen.
- Kannst du schwimmen?

### müssen (must)

- Ich muss arbeiten.
- Wir müssen lernen.

### wollen (want)

- Ich will Kaffee trinken.
- Sie wollen nach Deutschland fahren.

### sollen (should)

- Du sollst mehr schlafen.
- Ihr sollt pünktlich kommen.

### dürfen (may)

- Darf ich hereinkommen?
- Kinder dürfen hier spielen.

### mögen (like)

- Ich mag Pizza.
- Wir mögen Musik.

---

## Common Expressions

| German       | English      |
| ------------ | ------------ |
| Ich kann...  | I can...     |
| Ich muss...  | I must...    |
| Ich will...  | I want to... |
| Ich soll...  | I should...  |
| Darf ich...? | May I...?    |
| Ich mag...   | I like...    |

---

## Basic Rules

- Modal verbs are **irregular**.
- The **main verb remains in its infinitive form**.
- The **main verb goes to the end** of the sentence.
- Modal verbs express **ability, permission, obligation, advice, desire, or preference**.

Formula

> Subject + Modal Verb + Object + Main Verb

Examples

- Ich kann gut kochen.
- Du musst Deutsch lernen.
- Wir wollen heute einkaufen.
- Darf ich Ihnen helfen?
